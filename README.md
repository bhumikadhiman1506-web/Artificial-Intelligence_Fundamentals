# Artificial Intelligence Fundamentals

This project was created as part of a 1-week training session on
Artificial Intelligence Fundamentals.

The project demonstrates some basic applications of Artificial
Intelligence tools, including prompt writing, AI-assisted
summarization, grammar correction, and AI-generated visuals.

## Project Overview

The project explores how different AI tools can be used for
practical tasks such as:

- Creating prompts for AI-generated content
- Generating futuristic video concepts
- Summarizing educational content using AI tools
- Identifying and correcting grammatical mistakes
- Creating and animating visuals using AI tools

## Topics Covered

### 1. Prompt Creation

A prompt was created for a futuristic 1-minute video based on a
vision of the year 2050.

The prompt included ideas such as:

- Futuristic cities
- Flying vehicles
- Advanced AI-powered robots
- Smart devices
- Self-driving cars
- High-speed trains
- Holographic communication
- Environmental sustainability

### 2. AI-Assisted Video Summarization

An AI tool was used to summarize a video explaining the
relationships and differences between:

- Artificial Intelligence (AI)
- Machine Learning (ML)
- Deep Learning (DL)
- Generative AI

### 3. Grammar Correction

A paragraph containing grammatical mistakes was analyzed using
Grammarly.

The project shows how an AI-based writing tool can identify
grammar and sentence-related issues and provide corrections.

### 4. AI-Generated and Animated Visuals

AI tools were also explored for creating and animating visuals.

A futuristic city image was used to demonstrate AI-based
animation, with a prompt used to create an animated video clip.

## AI Tools Explored

- AI tools for video summarization
- Grammarly
- Runway AI
- NotesGPT
